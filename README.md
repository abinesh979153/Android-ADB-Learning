Android ADB Learning

A beginner-friendly Android development and cybersecurity learning project using Android SDK Platform Tools.

This repository documents ADB commands, Android concepts, SQLite basics, and practical device debugging exercises.

🎯 Project Objectives

- Learn Android Debug Bridge (ADB).
- Understand Android device communication.
- Explore Fastboot fundamentals.
- Practice basic Android debugging.
- Learn SQLite database basics.
- Understand mobile application security.

🛠️ Tools & Technologies

- Android SDK Platform Tools
- ADB (Android Debug Bridge)
- Fastboot
- SQLite3
- Windows 10
- Command Prompt (CMD)
